# 🛒 Blinkit Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Power BI Sales Analysis Dashboard** created using Blinkit grocery sales data.

The dashboard provides a detailed view of **sales performance, outlet characteristics, item categories, customer ratings, and outlet locations**. It allows users to analyze business performance using interactive filters and visualizations.

---

## 🎯 Business Objective

The main objective of this project is to analyze Blinkit's sales data and identify important business insights related to:

- Total Sales Performance
- Average Sales
- Number of Items Sold
- Average Customer Rating
- Outlet Performance
- Outlet Size
- Outlet Location
- Item Type
- Fat Content
- Outlet Establishment
- Sales distribution across different outlet types

---

## 🛠️ Tools & Technologies Used

- **Power BI Desktop**
- **Power Query** – Data Cleaning & Transformation
- **DAX** – Measures and Calculations
- **Data Visualization**
- **Microsoft Excel / CSV** – Data Source

## 📈 Dashboard Features

### 1. Outlet Establishment Analysis

A line/area chart is used to analyze sales performance based on the **Outlet Establishment Year**.

This helps understand how outlet performance has changed over time.

---

### 2. Fat Content Analysis

The dashboard analyzes sales based on **Fat Content**, including:

- Low Fat
- Regular

A donut chart is used to show the contribution of each fat-content category to total sales.

---

### 3. Item Type Analysis

Sales are analyzed across different grocery item categories such as:

- Fruits & Vegetables
- Snack Foods
- Household
- Frozen Foods
- Dairy
- Canned
- Baking Goods
- Health & Hygiene
- Meat
- Soft Drinks
- Others
- Seafood
- Breakfast

This helps identify how different product categories contribute to overall sales.

---

### 4. Fat Content by Outlet

A comparative analysis is provided to understand the distribution of **Low Fat and Regular products across different outlet tiers**.

This helps analyze product preferences across outlet locations.

---

### 5. Outlet Size Analysis

The dashboard analyzes sales based on outlet size:

- Small
- Medium
- High

A donut chart is used to visualize the contribution of different outlet sizes to total sales.

---

### 6. Outlet Location Analysis

Sales are analyzed according to outlet location tiers:

- Tier 1
- Tier 2
- Tier 3

This provides an understanding of how different location categories contribute to total sales.

---

### 7. Outlet Type Performance

The dashboard contains a detailed table comparing different outlet types based on:

- Total Sales
- Number of Items
- Average Sales
- Average Rating
- Item Visibility

This allows users to compare the performance of different outlet formats.

---

## 🎛️ Interactive Filters

The dashboard includes interactive slicers that allow users to filter the analysis by:

- **Outlet Location Type**
- **Outlet Size**
- **Item Type**

Users can select different combinations of filters to perform focused analysis.

## 🔍 Key Insights

Some observations available from the dashboard include:

- Total sales are approximately **$1.20 million**.
- The dashboard contains **8,523 items**.
- The overall average rating is approximately **3.9**.
- Different outlet tiers contribute differently to overall sales.
- Outlet size has a noticeable impact on sales contribution.
